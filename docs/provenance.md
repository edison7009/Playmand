# 来源与适用边界

## 0.2.0：Rust + Bevy 专项内容

0.2.0 按用户反馈重新定位为 Rust + Bevy 开发技能。新增技术资料依据 Bevy 0.19.1 的本地 crate 源码、对应版本官方示例和资料中的官方链接；ECS 示例为独立编写，在本仓库单独构建运行。具体覆盖见 [验证记录](../VALIDATION.md)。

0.1.0 的固定开发循环和强制报告要求已从技能入口移除。下文保留最初资料来源的历史说明，不代表新版仍以这些流程为核心，也不把来源项目测试当作本技能测试。

## 0.1.0 历史资料来源

本轮依据用户要求，先交付独立技能。经验来自维护者的两份本地材料：

- 《Playmand：产品定位与开发启动计划》
- 《Playmand：WithYou 开发复盘与实施建议》

原始规划、机器路径及开发对话保留在维护者本地；公开仓库提供以下经验摘要与自包含的排查手册，不依赖访问原材料。

2026-09-13 只读核对本机 WithYou 的 `native/AGENTS.md`、`native/Cargo.toml`、`native/VALIDATION.md` 及部分源码位置。Cargo.toml 当时固定 Bevy 0.19.1、Rust 最低版本 1.95；它们是来源项目事实，不是本技能安装依赖或所有项目的推荐版本。未重跑 WithYou 的历史游戏测试。

表中源码与验证文件是维护者核对过的来源索引，未作为公开附件，也不能由读者仅凭此表独立复现实验。公开技能保留症状、诊断方法和验收标准；后续独立宿主实测另记于 [验证记录](../VALIDATION.md)。

玩法最小循环、技能按需加载、安装冲突保护与评估步骤是本轮设计。它们不是 WithYou 已完成的产品功能，也不是独立模型实验已经证明有效的结论。
