# 游戏手感：奖励、升级与反馈

验证来源：[反馈示例](../../../../skills/playmand/examples/feedback-tiers/src/lib.rs)（纯 Rust，无依赖，在 CI 中测试），以及最初为 EchoBird 宠物制作、在浏览器中逐帧检查过的升级效果。与引擎无关：同一套节拍可以驱动 Bevy 系统、WebGL2 页面或 Macroquad 循环。

当游戏需要让奖励**有奖励的感觉**时读这一页：升级、收集、解锁、进化、通关。

## 给时刻分层

先定层级，再让每一级明显强于上一级。常见的阶梯：

| 层级 | 何时 | 时长 | 增加的内容 |
| --- | --- | --- | --- |
| 获得 | 有进度但还不是奖励 | 约 0.45 秒 | 能量流入、柔和发光、轻轻“咽一下”。**没有冲击、光环或迸发**，绝不能看起来像升级 |
| 升级 | 常见、会被反复触发的奖励 | 约 0.7 秒 | 下蹲、弹跳、一圈地面光环、少量闪光。短到可以连点 |
| 里程碑 | 少见（每十级、首领） | 约 1.3 秒 | 光柱、更高的弹跳、两圈光环、粒子、镜头轻推 |
| 终局 | 只有一次（满级、结局） | 约 2.4 秒 | 全部效果，然后**归于静止**：绝不循环 |

反复出现的奖励要短，少见的可以长。如果进度可能只完成一部分，这种情况需要自己的、更安静的反馈：沿用升级动画等于告诉玩家他升级了，其实并没有。

## 打磨一个时刻

- **预备、动作、跟随**：冲击前下蹲（y 方向缩放小于 1），上升时拉伸，落地时挤压。以脚底为中心缩放，x 和 z 方向按 1/√(y 缩放) 补偿以保持体积。
- **只有一个冲击时刻**：光环、粒子、闪光和音效都从这一刻开始。把它暴露为事件（`on_impact`），让音效正好对准，而不是等某个计时器。
- **镜头不要跟着跳。** 如果镜头每帧都按角色取景，就要在取景**之后**再叠加跳跃、挤压和旋转，否则跳跃看不出来。冲击时镜头推进几个百分点就足够强调。
- **形态变化要在变化之后落定。** 如果变形在动画最末尾才完成，就在后面加一小段落定（光环、粒子），再报告完成。
- 颜色：常见层级用产品的主色，少见层级用金色，粒子里混入角色自己的颜色，让效果属于它。

## 奖励来得比效果快时

玩家会狂点带来常见奖励的按钮。如果每次触发都让效果从头开始，在冲击时刻之前到来的触发会把冲击又往后推，于是快速连点时没有冲击、没有音效，数字也不动。应该：

- **效果还没到冲击时刻，就绝不从头重播。** 把下一级排进队列；当前效果一过冲击时刻，下一级就可以立刻接上，这样每一级都按顺序有自己的冲击。
- **或者让显示去追赶：** 真实等级立刻结算，屏幕上的经验条和数字去追它，显示的经验条每越过一级就触发一次冲击，看起来像计数器往上滚。
- 一次触发跨过多级时，按达到的最高档播一次，并显示"+N"。
- 让显示的等级紧跟真实等级：队列里有等级在等时，每一级播得更快（最短约原时长的三分之一），正在播的那一级也要一起加速（保留它的进度，动画才不会跳）。不要把很多级合并成一个迟到的"+6"。[示例](../../../../skills/playmand/examples/feedback-tiers/src/lib.rs)里的 `Rewards` 就是这样做的：每秒喂十次时，每一级仍有自己的冲击，显示最多落后三级。
- 按玩家真实的点击速度测（每 0.1 到 0.3 秒一次）：数几秒内的冲击次数，并确认显示的数字一直在动。

## 写成数据，只测一次

把效果写成 `(层级, t)` 的函数，返回普通数值：跳跃高度、挤压、发光、光环年龄、粒子年龄。渲染器只负责读取。然后不需要 GPU 就能测试关键点：每一级都比上一级强；获得层级没有冲击；跳跃先下蹲再升起；`t = 1` 时一切回到静止（跳跃 0、挤压 1、没有光环和粒子）；减少动态效果时只剩发光。

## 安全地运行

- 每个启动的效果都有一个**序号**，取消就是让序号加一。已经排进队列的旧效果帧会先检查序号，不匹配就什么都不做，所以它永远不会让已取消的效果跑完或触发回调。
- 冲击和完成**各自最多触发一次**，取消后绝不触发。切换角色、离开界面、隐藏窗口、卸载组件都算取消。
- 游戏状态（货币、等级、存档）由游戏自己的逻辑结算，不放在动画里。动画只报告完成，由游戏判断这次奖励是否仍然有效。
- 没有动画时停止帧循环；取消时释放粒子、缓冲区和计时器。

## 减少动态效果

用一段短而平稳的发光代替运动：不跳、不转、不闪、不推镜头、没有粒子，控制在半秒左右以内。真实的进度和最终结果仍然要看得见：减少动态效果也必须让玩家知道发生了什么。

## 常见坑

- 只完成一部分进度时播放了升级动画。
- 庆祝动画循环播放，或者在玩家反复触发的奖励上一挡就是好几秒。
- 音效按固定计时器在画面之后才响，或者在奖励真正发放之前就响了。
- 时长结束时效果还停在半路（光环还在扩、角色还被压扁）。
- 快速连点时效果不断从头重播，冲击一直到不了，数字直到最后才动。
- 已取消的效果因为一帧排队的旧帧仍然跑完了。
