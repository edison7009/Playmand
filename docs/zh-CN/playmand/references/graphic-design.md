# 平面设计：海报、社交配图与幻灯片

验证来源：[poster-design 示例](../../../../skills/playmand/examples/poster-design/src/lib.rs)。同一份内容在 CPU 上用 tiny-skia 和 Inter 可变字体排版并渲染，输出 A4 与 A3 印刷文件（300 dpi，3 毫米出血）、4:5 信息流配图、9:16 故事、链接分享图和 16:9 幻灯片，全部约 7 秒。每种版式都会检查：文字在安全区内、没有任何重叠（文字、分隔线或色块）、字号可读、对比度符合 WCAG；做这个示例的过程中，检查抓到了三个真实问题（见"常见坑"）。测试在 Windows 和 Linux 的 CI 中运行。

本页用于自己做的静态平面作品：海报、传单、社交配图、链接分享图、横幅、以图片形式输出的幻灯片、标题卡。会动的海报（静态图周围有实时的天气或光）属于[网页特效](web-wasm.md)或[视频](motion-graphics.md)；设计里用到的照片和细节丰富的插画来自用户或生成工具（见[素材流程](asset-pipeline.md)）。

## 先问清楚

用途、出现在哪里（印刷尺寸，或哪个平台）、文案、品牌包（颜色、字体、logo），以及用户喜欢的风格示例。没有示例的话，给两三个方向的小草图或提示词（见[美术方向](art-direction.md)）。

## 画幅

| 画幅 | 像素 | 出血 | 留空 |
| --- | --- | --- | --- |
| A4 印刷 | 300 dpi 下 2480 x 3508 | 每边 3 毫米（35 像素） | 左右约 7%，上下约 6% |
| A3 印刷 | 300 dpi 下 3508 x 4961 | 3 毫米 | 同上 |
| 信息流 4:5 | 1080 x 1350 | 无 | 6-7% |
| 故事 9:16 | 1080 x 1920 | 无 | 顶部 13%（顶栏），底部 18%（回复栏），左右 7% |
| 方形 | 1080 x 1080 | 无 | 6% |
| 链接分享图 | 1200 x 630 | 无 | 左右 6%，上下 10% |
| 幻灯片 16:9 | 1920 x 1080 | 无 | 左右 6%，上下 8% |

- 印刷：毫米换算像素是 `毫米 / 25.4 * dpi`。背景铺到出血边，文字放在安全边距以内，并把分辨率写进文件，印刷软件才会按正确尺寸摆放。
- 每种画幅单独排版，不要把一张图缩放套用：宽画幅把数据放在标题旁边的一栏，高画幅竖向堆叠。

## 版式与字体

- **层级**：小标签（小字、大写、加字距）、标题（最大的元素，行距约 1.0）、副标题、正文、数据（大数字配小标注）、行动号召。一个强调色只用在一两处，其余用正文色和中性色。
- **字号按页面短边计算**，这样标题在手机上和墙上读起来一样。标题放不下时逐步缩小，直到不超过三行，而不是让它一直往下排。
- **一个字族、多种字重**：可变字体一个文件就包含所有字重。用这个字体和它的字距数据来测量文字；测的是什么，画出来就必须是什么。
- **内容有主次。** 某个画幅放不下全部内容时，先删可选的部分（正文段落），而不是把任何文字缩到看不清。
- **装饰要给文字让路**：从角落溢出的大色块、圆环、分隔线。先试大尺寸，逐步缩小，直到版式通过检查。

## 每种版式都要检查

把这些做成自动检查，对每种画幅都跑一遍：

- 每个文字块都在安全区内。
- 文字不与其他文字、分隔线或实心色块重叠。
- 按文字实际所在的背景算对比度：正文至少 4.5:1，大字至少 3:1（WCAG）。品牌的亮色强调色用在小字上常常不达标；要为文字准备一个深一点的版本。
- 最小字号：印刷分辨率下 9 磅（300 dpi 下 37.5 像素）；在把图片显示成 375 点宽的手机上约 11 磅（1080 像素宽的图上是 32 像素）。
- 必需的内容一样不少，标题不超过三行。

然后用眼睛看：把所有画幅拼成总览图并排看，再按每张实际被看到的尺寸看，包括缩成小缩略图时。

## 导出

- 屏幕用 PNG。印刷用带出血、写入分辨率的完整文件，外加一张裁切后的预览。
- 示例不涵盖：CMYK 印刷色（很多印厂会自己转换 RGB，先问印厂）、PDF 输出、可编辑的幻灯片文件。用户需要可编辑的 PowerPoint 或 Keynote 文件时要直说：Rust 可以输出幻灯片图片或网页演示，可编辑文件要用宿主的文档工具来做。
- 字体必须授权允许嵌入和分发（SIL 开放字体许可允许；要随字体附上授权文件）。

运行示例：

```sh
cd examples/poster-design
cargo test --locked                          # 每种画幅的版式和检查
cargo run --release -- out                   # 输出 PNG 和总览图
python3 ../../scripts/check_asset.py out/a4-print.png out/slide.png
```

## 常见坑

前三条都是示例里的检查抓到的：

- 品牌强调色用在小字上：橙色小标签在纸色底上只有 3.7:1；为文字准备一个深一点的强调色就解决了。
- 装饰压到文字：标题撞上了强调色圆盘，一条分隔线穿过了正文最后一行。文字要和色块、线条比，不能只和其他文字比。
- 高画幅上的小字：1080 x 1350 的配图里，小标签只有 28 像素，低于 32 像素的下限。
- 一套版式缩放套用到所有画幅。
- 测量文字用的字体、字号或字距和实际绘制的不一样。
- 文字放进了出血区，或平台界面会遮挡的区域。
- 字体的授权不允许嵌入。
