# 验证与交付

先写玩家可观察的预期，再选验证方式。检查应读取系统运行后的实际结果，不只匹配实现中的常量或成功日志文字。

## 按改动选择最小充分证据

| 改动 | 必要关注点 | 有疑点或任务要求时追加 |
| --- | --- | --- |
| 玩法/交互 | 输入触发行为，反馈正确，完成/失败与重试可达 | 连续输入、边界、重复触发、重置污染 |
| 状态/草稿/存档 | 最短故障序列，修改前失败与修改后通过；隔离数据保存/重载 | 页面交错保存、旧格式、写入失败语义 |
| UI/配色/布局 | 实际渲染和最终控件边界，受影响的交互状态 | 长文本、分页、语言、支持的视口/DPI |
| 模型/动画/渲染 | 实际相机画面、资源就绪，动作时间序列 | 多实例、替换、隐藏、关闭、重开和资源稳定性 |
| 性能/资源增长 | 固定条件的前后测量，或明确范围的计数检查 | 长时、极限数量、后台/恢复；不能把短测外推 |
| 打包/路径/窗口 | 包内启动和资源加载；原生行为用对应 OS 证据 | 不同工作目录、空格/中文路径、支持平台 |

项目已有必做检查仍需执行。视觉小改动不自动触发全场景跑分；缺 GPU 时可继续完成逻辑/构建检查，但画面验收保持未验证。

## 证据分别能证明什么

| 层次 | 可以支持 | 不能直接支持 |
| --- | --- | --- |
| 编译/逻辑测试 | 类型、所测规则与边界 | 最终画面或真实玩家流程 |
| 调试状态注入 | 指定状态下的渲染或分支行为 | 玩家能够通过输入到达该状态 |
| 引擎合成输入 | 经游戏输入/事件路径的行为 | OS 焦点、真实输入法候选窗或硬件输入 |
| GPU 截图/回放 | 本次场景指定时刻的渲染/连续变化 | 未拍到的系统窗口；离线视频编码帧率不代表实时 FPS |
| 原生窗口/API 检查 | 实际读取或操作到的 OS 行为 | 仅请求最小化不能证明窗口已最小化及可恢复 |
| 性能采样 | 记录条件下的计时或资源统计 | 工作集不能当显存；窗口帧间隔不能当 GPU 纯耗时 |

流程检查可用调试注入建立初始状态，但到目标状态必须经过被验收的输入路径。保存修改后在新会话复验，排除临时状态与旧实例。

## 一次运行的记录

优先写入项目已有 VALIDATION 或等价记录，不强行引入新文件体系。记录足够重现本次结论的内容：

```text
任务与预期：玩家做什么、应看到什么
版本：源码提交/工作区改动说明；涉及构建混淆或交付时附产物哈希
运行：构建入口、程序路径、工作目录、命令与退出码、会话/PID
条件：隔离数据目录、分辨率、机位、时间/种子；仅记录本任务相关项
操作：有顺序的步骤、经过的输入层次、重置方式
观察：实际状态、日志及已查看图像/序列的位置
结论：通过 / 失败 / 未执行 / 环境不可用；分别列出检查项
限制：缺什么证据、下一步最小复现入口
```

日志含敏感信息时保存必要摘要或脱敏证据，不把个人数据打进共享经验包。只管理本次拥有的会话和产物。异步任务返回 ID 后还需等最终状态，超时或取消都不是通过。

## 性能比较与玩家包

性能前后保持相同硬件、分辨率、镜头、素材/实例数量、时段、预热、测量区间及实际前后台/焦点状态。避免编译器或另一个渲染实例干扰。记录原始样本及适用的中位数/P95；条件不同的样本单列，不能通过只挑更快的一次制造收益。

交付玩家包时检查：目标程序是本次构建；资源不依赖开发目录；相关输入流程、保存/退出可用；开发接口未默认开放。源码运行成功和包内启动成功分别记录，不能用“打包命令退出 0”替代后者。
